=== zsxq视频网页全屏功能使用说明 ===
版本: 1.2

【基本功能】  

• 点击"全屏"按钮可进入/退出网页全屏模式  
• 按ESC键可退出全屏模式  
• 空格键可播放/暂停视频  

【按钮操作】  

• 左键拖拽：移动全屏按钮位置  
• 右键点击：打开上下文菜单  
• 双击：无特殊操作（避免误触）  

【上下文菜单功能】  

• 记忆位置：启用/禁用按钮位置记忆功能  

- 启用后：刷新页面会保持按钮位置  
- 禁用后：刷新页面按钮回到默认位置（右上角）  

【键盘快捷键】  
• 方向键左右：  

- 短按：快进/快退5秒  
- 长按（300ms以上）：3倍速播放  
- 松开：恢复正常速度  

• 方向键上下：  

- 调整音量（每次±10%）  

【重要提示】  

• 按钮位置记忆功能默认处于关闭状态！  
• 如需启用记忆功能，请右键点击按钮并选择"记忆位置"  
• 该工具仅供学习使用  
• 全屏模式下视频容器会覆盖整个视窗  
• 拖拽按钮时点击不会触发全屏功能  

【日志控制】（bata）  
• 在控制台输入 toggleZsxqLog(1) 启用详细日志  
• 在控制台输入 toggleZsxqLog(0) 禁用详细日志  

如有问题，请检查控制台日志。  
 
**如何使用该脚本**  
1.谷歌浏览器或者chrome内核心的浏览器，支持油猴插件的浏览器，下载安装油猴，新下载的伙伴 需要打开浏览器的开发者模式否者不生效  
2.新建脚本将文档中的脚本添加进油猴  
3.重新打开小傅哥的星球即可
