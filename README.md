# Knowledge-Planet-Webpage-Full-Screen

用于知识星球网页全屏，项目仅供学习使用，请勿非法使用，如有侵权请联系作者进行删除。

## 功能说明

=== zsxq视频网页全屏功能使用说明 ===  
版本: 1.3

### 【基本功能】  

• 点击"全屏"按钮可进入/退出网页全屏模式  
• 按ESC键可退出全屏模式  
• 空格键可播放/暂停视频  

### 【按钮操作】  

• 左键拖拽：移动全屏按钮位置  
• 右键点击：打开上下文菜单  
• 双击：无特殊操作（避免误触）  

### 【上下文菜单功能】  

• 记忆位置：启用/禁用按钮位置记忆功能  

  - 启用后：刷新页面会保持按钮位置  
  - 禁用后：刷新页面按钮回到默认位置（右上角）  

### 【键盘快捷键】  

• 方向键左右：  

  - 短按：快进/快退5秒  
  - 长按（300ms以上）：3倍速播放  
  - 松开：恢复正常速度  

• 方向键上下：  

  - 调整音量（每次±10%）  

### 【重要提示】  

• 按钮位置记忆功能默认处于**关闭状态**！  
• 如需启用记忆功能，请右键点击按钮并选择"记忆位置"  
• 该工具仅供学习使用  
• 全屏模式下视频容器会覆盖整个视窗  
• 拖拽按钮时点击不会触发全屏功能  

### 【日志控制】  

• 在控制台输入 `toggleZsxqLog(1)` 启用详细日志  
• 在控制台输入 `toggleZsxqLog(0)` 禁用详细日志  

> 如有问题，请检查控制台日志。

## 安装与使用

### 如何使用该脚本  

1. 在 Chrome、Edge 或其他支持 Tampermonkey（油猴）插件的浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/)  
2. 新建用户脚本，将本项目中的 `.user.js` 文件内容完整复制进去并保存  
3. 打开知识星球（https://wx.zsxq.com/）的视频页面，稍等片刻即可看到右上角的“全屏”按钮  

> **注意**：首次使用时会弹出使用指南对话框，阅读后点击“我知道了”即可关闭。

### 关于油猴脚本不生效的问题  

以 Chrome 和 Edge 浏览器为例：

1. 确保已开启浏览器的**开发者模式**  
   ![开启开发者模式](/img/开启开发者模式.png)

2. 在扩展管理页面中，确保 Tampermonkey 已启用  
   ![管理拓展](/img/管理拓展.png)

3. 在 Tampermonkey 设置中，确认已**允许访问文件网址**（如从本地加载）或对应网站权限  
   ![允许用户脚本](/img/允许用户脚本.png)
